# Changelog

All notable changes to exposer, newest first. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- The footer credits the tools that built the site: "Generated by exposer and Hugo", linking to both projects. When an imprint page is set, its link comes first.

### Changed

- **Breaking:** the `footer_note` setting in `exposer.yaml` is now `footer_line`. A configuration still using the old name fails with a message saying so.
- **Breaking:** a setting exposer does not know now fails the build and names it, instead of being silently ignored. A misspelt key no longer leaves the site built on a default.
- Photos gain a 1200 px size, so phones and small laptops download about a third less per photo.
- The fullscreen script is minified: under 1 KB gzipped, now served as `fullscreen.min.js`.
- Messages, help text and the configuration template are written in plain words, without the specification's internal references.

## [0.1.2] - 2026-09-21

### Added

- Ready-to-run binaries for Linux and macOS, on amd64 and arm64, with every release. Installing no longer needs Go. Each archive is listed in `SHA256SUMS` and attested by the workflow that built it. The macOS binaries are not signed by Apple; see the README.

## [0.1.1] - 2026-09-21

This release has no downloadable binaries: its tag predates the release workflow. Install it with `go install`, or use 0.1.2, which is otherwise the same.

### Added

- `exposer init <library>` writes a commented configuration, holding exactly the defaults, to `<library>/_data/exposer.yaml`, and never replaces an existing one.
- `exposer --version` reports the release and the Hugo version it renders with.

### Changed

- The README shows an example of a generated site, and warns that Ubuntu 24.04 LTS ships only ImageMagick 6, which has no `magick` command.

## [0.1.0] - 2026-09-21

The first release: a static photography site generator that reads an offline library of originals and darktable XMP sidecars and writes static files.

### Added

- One binary: `exposer build <library>` runs the whole pipeline. The theme and schema are compiled in, and Hugo 0.166.0 is downloaded and checksum-verified on first use.
- Albums, tags, locations, a timeline, an "All" page, a Gear page and a Tags page, with a page for each photograph inside every listing it belongs to.
- JPEG and AVIF images in a content-addressed cache, byte-identical rebuilds, originals that never reach the published site, and a build that fails if a published photograph cannot be reached.
